## Overview
This repository contains a polished, responsive HTML portfolio piece titled **"The Skill Shift: Why Lifelong Learning Is the New Job Security"**. It demonstrates a project-first approach to portfolios — short, verifiable mini-project ideas, a downloadable one-page summary, and accessible, print-optimized markup.

## Highlights
- ✅ Responsive single-page HTML (`index.html`)  
- ✅ Downloadable PDF summary (`skill-shift-summary.pdf`)  
- ✅ Branded favicon (`ar-favicon-64-B.svg`)  
- ✅ SEO & Open Graph meta tags for social sharing  
- ✅ Print styles for clean "Save as PDF" exports
